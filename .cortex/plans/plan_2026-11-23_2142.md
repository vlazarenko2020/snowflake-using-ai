## Changes
I'll create three dynamic tables in `AVELTO_RENTALS.SILVER`, each with `TARGET_LAG = '1 minute'`, `WAREHOUSE = COMPUTE_WH` and `REFRESH_MODE = AUTO`. Column names will be uppercase (no quotes needed), text will be trimmed, and every row is kept as-is, so the grain doesn't change.

1. **`STG_COUNTRIES`** (one row per country): `country_id NUMBER`, `country_code` (uppercase), `country_name`, `region`, `currency_code` (uppercase), and `has_valid_currency`. That flag is a LEFT JOIN check against `BRONZE_CURRENCIES`.
2. **`STG_CURRENCIES`** (one row per currency): `currency_code`, `currency_name`, `symbol`, `usd_exchange_rate NUMBER(18,6)`, `decimals NUMBER`.
3. **`STG_BRANCH_CATEGORY_AVAILABILITY`** (one row per branch and category):
   - `branch_id NUMBER`, `branch_name`, `category_id NUMBER`, `category_name`, `is_offered BOOLEAN`.
   - `is_known_branch` and `is_known_category`: LEFT JOIN checks against `BRONZE_BRANCHES` and `BRONZE_CAR_CATEGORIES`.
   - `branch_name_matches`: whether the repeated branch name matches the branches table.
